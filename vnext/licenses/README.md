# Pinned distribution notices

These verbatim license/NOTICE files come from the exact pinned upstream tags.
provenance.json records source URLs and SHA-256 digests. Cua's driver Cargo
manifest declares MIT; the top-level pinned LICENSE is preserved. Codex uses
Apache-2.0 and includes its pinned NOTICE. Styx's repository license is included.
Node's prepared official distribution supplies its own LICENSE with bundled
third-party notices; ws's upstream LICENSE is already included with that package.
Host release manifests cover the notice files; Styx.app seals its Cua/Styx
notices before code signing.

This preserves top-level distribution notices. It is not a complete transitive
native binary license audit or a substitute for upstream Cargo/native SBOMs.
The npm CycloneDX SBOM is a separate VNext JavaScript dependency graph, not a
claim that a Host contains every Gateway dependency or native transitive crate.
