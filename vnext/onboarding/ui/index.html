03

执行与进度

每次只授权一个已准备好的步骤。刷新后可继续读取本地记录。

    审批与中断

    加入环境需要管理员在独立的受信任管理端批准设备。状态不确定时不会自动重放操作；保留本地状态并先诊断。步骤成功是执行记录，不代表系统服务或 ChatGPT 账号已完成验收。

    维护与诊断

    诊断通过上方“检查 Host”步骤执行，只运行核心提供的固定检查。

    只作用于当前进程拥有的本机 Gateway，不停止 Host 系统服务，不控制其他安装。关闭后，已有步骤的成功记录不会被当作运行状态。

    本机 Host 系统服务

    安装、启动和停止都需要明确授权。启动会启用登录后自动运行；停止会关闭自动运行。实际登录启动状态以本机返回值为准，未知状态不会推断为已启用。
