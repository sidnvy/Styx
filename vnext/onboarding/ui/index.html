    B

    准备创建材料

    本机可导出插件 ZIP，包含刚才的外观设置。导出前 Styx 会检查本机工具连接的认证与工具发现，以及已配置的隧道绑定。

    本机导出不代表隧道从云端可达、账号认证通过或插件已上传。包中不会放入原始工具令牌；不要把密钥写入描述或发到聊天。

    C

    在官方账号中创建插件

    打开官方 ChatGPT 插件页面 ↗

    在目标账号／工作区使用页面提供的“添加自定义 MCP 服务器 → Tunnel → 创建为插件”，选择 Styx 的专用隧道，并按页面支持的字段填写名称、描述和图标。

    若你使用的 Plugin Creator 支持上传 ZIP，可以把刚导出的包交给该工具（例如在 Codex 对话中调用受支持的 Plugin Creator）。此处不会自动上传；不要假设普通网页提供 ZIP 上传按钮。

    创建地址保存后会固定指向同一个插件。若确需更换，请先切换为“复用已有插件”，明确填写并保存新的官方插件地址，再重新确认安装。

    此版本尚未提供插件创建材料与本机记录，请使用完整 Styx App 重新打开；不会把缺失接口显示为已完成。
